**How can I ensure that my code, program, or software is functional and secure?**


The best way is by following testing and security principles throughout the entire software development life cycle. By adopting TDD amnd writing tests and integration before the code it improves design and testabiity. Also principles like SOLID, KISS, and DRY keeps code functional, secure, and easy to debug. Lastly applying the principle of least privilege into code and controling input validation ensures that software is both functional and secure.

**How do I interpret user needs and incorporate them into a program?**


I use interviews to gather deeper insight so I can understand their motivations and what exactly do they want. Observing behavior with analytic tools and conducting user tests allow me to see how users act. Lastly analyzing feedback and reviews help with understanding problems and ensuring I have a clear understanding of what users want.

**How do I approach designing software?**

My approach to designing software is a very methodical one. First I like to organize and know the requiremnts, then I write pseudo code to the best of my ability. Next I try to implement that code with comments to keep track of what I am doing. Lastly I test the code/look for errors whether they are logic errors or syntax untill the code is satisfactory.
